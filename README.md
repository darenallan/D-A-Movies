# D&A Movies

Application web de découverte des **films populaires du moment**, réalisée comme projet final du cours **CS50**. Elle s'appuie sur l'API de The Movie Database (TMDb) et affiche une grille de films dans une interface sombre inspirée des plateformes de streaming.

Vidéo de démonstration : https://youtu.be/dtnpHftvOEA

## Contenu

- `Templates/index.html`, `Templates/accueil.html` : pages
- `Statics/scripts.js` : appels à l'API TMDb et rendu de la grille
- `Statics/styles.css`, images de fond

## Lancer

Ouvrir `Templates/index.html` dans un navigateur.

> La clé TMDb est écrite dans `Statics/scripts.js`, donc visible par tous. Pour un usage public, utiliser une clé dédiée et restreinte, ou passer par un petit proxy serveur.
